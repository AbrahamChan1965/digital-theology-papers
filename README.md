# Digital Theological Paper Collection (`digital-theology-papers`)

**Repository:** `https://github.com/AbrahamChan1965/digital-theology-papers`  
**Target Web Portal:** `https://papers.wordandspirit.com` (Root Domain: `wordandspirit.com`)  
**Author & Architect:** Rev. Dr. Abraham Chan (陳曉東牧師)

## Overview
A bilingual (Traditional Chinese & English) theological research repository exploring digital theology, liturgical time (*Chronos* × *Kairos*), AI-assisted ministry, and ecclesiological action for scattered local congregations within the **Word and Spirit Operating System (WNS-OS)** ecosystem.

## Repository Structure
- `index.html` — Swiss/Milanese minimalist bilingual web portal ready for Cloudflare Pages (`papers.wordandspirit.com`)
- `papers.json` — Master metadata registry for all collected papers
- `llms.txt` — AI-readable index enabling future Gemini, Claude, and GPT sessions to cite and build upon prior papers
- `AGENTS.md` — Cross-agent editorial and theological contract
- `papers/<slug>/zh/paper.md` — Traditional Chinese edition
- `papers/<slug>/en/paper.md` — English edition
